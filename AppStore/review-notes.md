# App Store Review Notes Draft

AtriaWall AI is a SwiftUI gallery wall planning app for homeowners. It lets users create wall projects, set dimensions, add frames, import photos, generate AI layout plans, preview with AR, and create hanging guides with nail positions.

Subscriptions are managed through RevenueCat and unlock Pro access. The planned entitlement is `pro` with weekly, monthly, and yearly subscriptions only.

The app uses the camera only for AR wall preview. The app uses photo library access only when users import artwork or family photos into a frame.

No TestFlight submission was performed from this repo setup.
